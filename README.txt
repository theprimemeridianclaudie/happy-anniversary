OUR FIRST YEAR — MINI WEBSITE

1. Put three MP4 videos into the folder named "videos" with exactly these names:
   01-how-it-began.mp4
   02-little-moments.mp4
   03-to-more-adventures.mp4

2. Open index.html in your browser to preview. Some browsers require a local web server for playback; publishing the site resolves that.

3. To edit any wording, open index.html in a text editor. You can change the headings, captions and letter without changing any code.

4. To publish: create a free account at Netlify (netlify.com), then drag the entire anniversary-site folder into Netlify Drop (app.netlify.com/drop). It will generate a link. Large video files may exceed hosting upload limits; if so, use compressed MP4 files or host videos separately.

PRIVACY: A site with a public URL is not truly private, even if you only share its link with Ivan. For private videos, choose hosting with proper access controls instead.
